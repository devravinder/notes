# IntelliJ shortcuts

- `Alt + Shift + Insert` toggle block/column mode (search 'Column Selection Mode', keep OFF)
- `Shift + F10` run
- `Ctrl + Shift + /` block comment/uncomment
- `Alt + Shift + select(cursor)` multi cursor
- `Ctrl + Shift + up/down` move line up/down
- `Alt + Insert` code generation
- `Ctrl + Shift + F` find/search
- `Shift + Shift` global search
- `Ctrl + Shift + R` find & replace
- `Ctrl + E` recent files
- `Ctrl + Alt + O` remove unused imports
